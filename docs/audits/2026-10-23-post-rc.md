## Findings for a later point upgrade

### #638 — active LAN probe network ownership (P2)

`LanProbe.kt:55–77` captures a current Wi-Fi/Ethernet network and its address/prefix but discards the network, then queues up to253 requests through an unbound client. A default-network change can open remaining old-subnet requests on a new default, potentially cellular, and mix results across network identities. `ConnectScreen.kt:52` keys permission/round, not network. This conflicts with the probe’s explicit carrier exclusion; it is separate from Q1/#39’s accepted saved-address/auto-connect product policy.

Pinned OkHttp4.12.0 published sources use/inherit `SocketFactory.getDefault()` (`OkHttpClient.kt:485,517`; `RealConnection.kt:284–290`). Source JAR SHA256 `d91a769a4140e542cddbac4e67fcf279299614e8bfd53bd23b85e60c2861341c`. Android17 `Network.java:273–303` documents a per-network factory that fails after network loss ([source](https://android.googlesource.com/platform/packages/modules/Connectivity/+/refs/tags/android-17.0.0_r1/framework/src/android/net/Network.java)). Root independently read the affected application path; actual packets/handover behavior were not measured.

A later patch should retain network identity, bind per-round sockets without changing process/global network settings, validate current usable capabilities before requests/publication, and cancel obsolete rounds. VPN identity can survive underlying transport changes; binding alone is not proof of zero cellular packets. Do not bypass VPN to select its underlying Wi-Fi network. Ambiguous transport and asynchronous callback races need explicit policy/testing. [Maintained state](issues/638.md).

### #639 — synchronous collection display projections (P2)

`MuonApp.kt:191–203` sorts songs/artists/albums synchronously inside composition and filters/sorts artist/album search results before display limits. `TrackSearch.kt:37–51` traverses/sorts full collections. Accepted inputs permit50,000 playlist entries and100,000 artist memberships; the comment assuming small artist/album collections is unsupported. Ordering/query/library changes block UI work for the duration of these calculations, including for hidden tabs. This is distinct from #244’s implemented API-response IO projection.

Main-thread execution/scaling is source-confirmed; no measured jank duration, ANR or OOM is claimed. Move projections into cancellable worker work, preserving snapshot/origin/order/query ownership and adding deterministic replacement/stale-publication tests. Existing sort/search behavior must stay unchanged. [Maintained state](issues/639.md).

### #640 — narrow direct signing-secret exposure; identify timing artifacts (hardening/P3)

`android.yml` restores signing files before a combined assemble/test/lint invocation with the password in the Gradle environment. Root confirmed the ordering on both actual main and candidate. Only APK signing needs the credentials; explicit unit/full-lint checks can run first. This is a direct exposure window, not demonstrated compromise and not a complete security boundary: earlier same-runner code can persist or modify the workspace, AGP/assemble can invoke implicit checks (including vital lint), and compromised build tooling remains trusted later. Do not disable checks or claim this resolves the deferred provenance work.

The separate follow-up moves all existing explicit test/full-lint tasks before key restoration and keeps signed assemble, identity checks, publication and cleanup. Timing-only artifacts currently use `app-debug-<sha>`, despite their version/banner/BUILD markers; use a distinct timing artifact name while retaining package/signing and nonpublication guards. Timing-mode labeling applies only to the candidate; secret ordering also exists on main. The sequencing patch passed .1335 and actual report/APK verification. All four explicit checks finished before restoration; later signed assembly and identity checks passed. The final signer-guard patch below still requires final-head CI;120 CI/9 release-policy checks passed locally. Timing-only/manual mode was not dispatched; all four naming combinations are checked against the real expression locally. [Maintained state](issues/640.md).
