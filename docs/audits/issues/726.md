## Source findings and behavior

Original guard observes pinned DefaultEbmlReader header reads before string/binary arrays, unknown-length sniff growth, backed Vorbis private laces, unique track/chapter/cue retention, and retained native master frames. It preserves actual factory/options, data bytes, source reopens and native identity. Proposed policies:4MiB element,16MiB metadata,4096 entries,64KiB sniff,128 observed track keys including native default0,4096 nonzero chapter IDs,65536 cue positions and4096 native frames. User provisionally accepted4096-frame/long-live-WebM restriction; other real compatibility remains pending. [Original source/limits](../2026-10-27-matroska-admission.md).

Native writeSubtitleSampleData allocates prefix+twice the text sample before its body. New #728 captures bounded native text IDs and observes the Block/SimpleBlock track varint before that allocation. Refuse text Blocks above existing4MiB element budget; no new payload buffer, per-sample ledger, peek/reset or byte rewrite. Audio and unknown-track blocks remain native. Tests cover default/missing-number0,1/2/8-byte track varints, known/unknown length, actual seek, large audio and ordinary native-transcoded SubRip delivery. Lacing/framing counts toward the conservative per-Block cap. [Extension](https://github.com/averylicious/muon/blob/codex/mkv-metadata-admission-oct27/docs/audits/2026-10-28-matroska-text-block-admission.md).

Default extraction-time subtitle parsing precedes downstream queue limits. Native PGS can inflate <1KiB to about256KiB and reserve32KiB bitmap data from14bytes in modest witnesses. #743 uses supported built-in SubtitleParser.Factory.UNSUPPORTED plus disabled text selection; both are necessary because TextRenderer advertises legacy raw formats but fails if selected. Muon has no caption consumer; lyrics/tags and audio/video are intended unchanged. This does not fix separate raw subtitle scratch or every codec allocation. [Policy/contracts](https://github.com/averylicious/muon/blob/codex/unused-subtitle-parsing-oct28/docs/audits/2026-10-28-unused-subtitle-policy.md), [witness/source](https://github.com/averylicious/muon/blob/24f5f59bd3b7f1f857d1f73592a5b25f53d847f4/docs/audits/2026-10-28-matroska-subtitle-buffer.md).
