## Confirmed source boundaries

- Ordinary `Mp4Extractor` allocates parsed leaf buffers before body/file/parent bounds, retains moov leaves, and builds normal/rechunk/edit/accumulated tables from metadata declarations. Compact fixed-size tables can amplify their declared counts. Metadata is bounded separately from mdat/audio.
- Shared `Sniffer` can expand its search at moov/uuid, grow a peek buffer on skipped metadata and allocate ftyp before its body peek. Both factory MP4 candidates reach it.
- Fragmented `parseTruns` sums counts before `TrackFragment.initTables` allocates four arrays with25% headroom; tfhd/trex defaults permit no per-sample trun payload. Parsed leaf and PSSH key-count paths also need admission.
- **The default factory enables MFRA seek-map reading**, unlike the bare fragmented constructor. Its tail route checks integer/file ranges but can still allocate the claimed mfra suffix before its full body read. Tfra backing checks bound later tables to that suffix; this is not an unrestricted-count finding for tfra.

## Production behavior / remaining work

Simple proven raw entries retain efficient rechunk admission.
