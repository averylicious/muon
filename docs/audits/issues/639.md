## Finding and implementation

Library song/artist/album ordering, collection search and browse projections can scan and sort the full loaded library in composition before display limits apply. This work can delay interaction on larger libraries; no measured device improvement is claimed.

The focused port takes only seven runtime/test files from old draft #642 (`a51098eb9084ec6e829354de5693a7c3b03cbeac`), excluding its inherited CI/documentation stack. Ordering and search run on cancellable workers with private locale collators. Snapshot, origin, order and locale identify each projection, and composition rejects an old owner immediately. Group browse is computed once with grouping. Source loops/comparisons observe cancellation.

Preserve stable ties, the existing debounce and completed-query token, full-library queue behavior, and hoisted scroll state. Late collection sources recompute their matches without restarting the song query or resetting its list. While a song order is loading, actions cannot enqueue an older order. No schema/dependency, package, signing or publication changes.
