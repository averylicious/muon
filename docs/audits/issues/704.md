## Source and proposed behavior

Pinned Media3 1.11.0 `Id3Peeker` allocates the declared leading tag before reading its body; maxTagPeekBytes is a header search limit. Initial admission checks cumulative tags/padding before every default extractor sniff/initial read, retaining factory options/identity and seek/release. Decoded admission separately budgets native text/frame resource cost; invalid-encoding and supplemental-decoder regressions remain covered.

Actual TS `Id3Reader` and ADTS readers send partial ID3 data into SampleQueue before sampleMetadata. Proposed `TimedId3Admission` counts unfinished writes and refuses **before** forwarding beyond4MiB, retaining truncated PES bytes in the count. No header/drop heuristic, payload staging or growing reset registry; audio and unrelated formats stay native. Realistic native queue reset/seek and cleanup are covered by the four new tests. Root checked pinned TS trackIds/reader initialization, so repeated native PMT parsing does not reset the counter invisibly.

**Compatibility remains proposed, not accepted:** an unfinished timed tag above4MiB would stop that stream with the existing fixed large-tag notice. Leading-tag limits already refuse unusually large valid files; supplemental decoded cost is dropped as optional metadata. No whole-audio cap or original-byte modification. [Detailed timed guard/contracts/attribution](https://github.com/averylicious/muon/blob/codex/id3-frame-admission-oct27/docs/audits/2026-10-28-timed-id3-admission.md); [native witness](https://github.com/averylicious/muon/blob/codex/timed-id3-buffer-oct28/docs/audits/2026-10-28-timed-id3-buffer.md); [earlier prefix history](https://github.com/averylicious/muon/blob/57bbf72c5d3400968790981e3b50931fd6f709f7/docs/audits/issues/704.md).

ProgressiveMediaPeriod interval gating and DefaultLoadControl allocator/heap thresholds qualify whole-player allocation. Actual ExoPlayerImplInternal has a four-second STUCK_BUFFERING_NOT_LOADING detector when its predicates hold; indefinite buffering is not established. Native decoder copies and other codecs/sample types remain separate. Queue reset without extractor seek can conservatively retain the input count; no universal heap/Binder claim.
