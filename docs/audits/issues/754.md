## Application reachability — qualified

The app has no direct ObjectInputStream/Serializable store, but AOSP android-9.0.0_r61/API28 can deserialize unrelated Bundle values before StorageReviewEntry's string capability comparison. MainActivity is exported, BaseBundle.getString first unparcels the map, Parcel's VAL_SERIALIZABLE uses the ActivityThread-supplied app loader. A result cast or RuntimeException catch does not bound allocation. This is source reachability, not a phone/Binder exploit or a claim about every Android/OEM release.
