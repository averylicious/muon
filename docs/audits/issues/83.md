## Current implementation

Recorder journeys require the actual destination/play/pause/return state instead of silently skipping missing controls. Package-scoped selectors, at-least40dp rows, permission-user checks and Benchmark-only cleanup remain. Queue gets at most four upward content swipes within Benchmark's observed default-display window, with foreground and visible-bounds checks. Entry selection is positional; physical short-window/large-font traversal is not proven by compilation.

A separate opt-in **measurement** tools build creates a minified/profileable/non-debuggable Benchmark target, with a matched helper and an explicit mode marker. Normal recording remains unminified. Two Macrobenchmark cases compare one measurement APK using `None` versus `Partial(Require, warmups=0)`, ten cold **first Connect-frame** iterations each. They do not measure library-ready, playback or scrolling; broader journeys remain engineering/measurement work after the controlled pilot. Existing APK profile rules are not replaced.

The harness requires API37+ both on device and target app, user0, denied Benchmark LAN permission, the right mode, and explicit `muonAllowBenchmarkDataReset=true`. It clears **only Benchmark** before compilation, checks the intended first screen, and stops only that target if armed. [Protocol and limitations](../../baseline-profile.md#matched-first-frame-experiment). Historical device permission does not authorize running it now.

Both tool APKs use the repository's pinned debug signer. The older helper used an ephemeral runner key; do not silently uninstall a mismatched installed helper. The pre-upload gate checks exact APK pair, signers, target identity/non-debuggable/profileable mode, and self-instrumenting helper. Existing Android runtime identities and signing keys are unchanged.

New paired-source binding labels both manifests and the helper with the full source commit. CI checks both labels; the helper checks the installed target's source and same-signature identity before any grant/reset. Unknown/local or mixed pairs fail. This prevents accidental pair mixups; it is not independent compiler, dependency or publisher attestation.
