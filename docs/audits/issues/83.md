## Recorder fix and remaining validation

Every journey now waits for its destination: list, album/artist and return, playback, Now Playing, Queue and return, Pause taking effect, then player closing. A missing target fails with a timed message instead of silently succeeding. Failure cleanup attempts Pause only in Benchmark, preserving the original error.

- Selectors are package-scoped. Entry selection remains positional: enabled clickables at least 40 dp high within the largest scrollable, excluding `Order:` controls. Wrong destinations now fail; actual tile selection still needs traversal testing.
- Queue supports the landscape icon and portrait text button. A button below the fold at large font/short window can still cause a clear failure; scrolling it into view is not implemented.
- On API 37+, grant local-network access once before collection and verify this instrumentation user's permission through PackageManager. The compiled self-instrumenting helper already inherits `QUERY_ALL_PACKAGES` from its test dependencies, so the target is visible; no extra query or permission was added. Earlier supported APIs skip that grant.
- Keep Benchmark's separate package and storage gate. Do not use the installed frozen RC, expand this into saved/SD stress, or accept stale exported files as a new successful recording.

Pinned API evidence: Google's Maven sources for `uiautomator:2.3.0` confirm `Until.gone`, `descStartsWith`, package/enabled selectors and child-object/description APIs. `benchmark-macro:1.5.0` confirms profile export occurs after successful collection, and `CompilationMode.None()` / `Partial(BaselineProfileMode.Require, warmupIterations = 0)` support the planned comparison. Versions remain in build files.

## Prepared first-frame measurement

An opt-in **measurement** dispatch builds the same separate Benchmark package with release minification/resource shrinking and the shipped profile; ordinary recording builds remain unminified. Both helpers/targets declare and check their mode, preventing accidental profile recording from an obfuscated measurement target. No release package ID, signing path or published APK changes.

`StartupBenchmark` compares ten cold first-frame iterations on the same APK under `None()` versus `Partial(Require, warmupIterations=0)`. API37+ and denied Benchmark LAN permission keep the fresh Connect journey independent of changing Tauon/discovery responses. It explicitly requires permission via a reset argument to clear **only Benchmark data before compilation**, then verifies the destination. It does not measure loaded-library readiness, playback or scrolling; OS/filesystem caches are not flushed. Counterbalanced batches and thermal/configuration review remain required. [Protocol](../../baseline-profile.md#matched-first-frame-experiment).
