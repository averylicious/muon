`DownloadArtworkWork` replaces per-cover executor closures with one draining task and bounded typed jobs:128active/waiting jobs and256KiB logical ID/URL text/overhead. Exact-duplicate fetches coalesce; different addresses cannot replace a same-ID fetch. A refused optional cover does not stop the audio save commands; new-save feedback discloses initial cover admission refusals. Pending optional fetches can be displaced by cleanup; missing artwork uses the existing placeholder.

Removal replaces a waiting fetch, cancels an active one, and deletes again after its late publication. No permanent per-ID cancellation/tombstone collection. Cleanup never displaces cleanup; if the bounded queue cannot admit it (or executor submission fails), removal performs one internal cover-file deletion on the caller. This is a possible small main-thread disk operation, not network/audio/index IO; storage latency is not measured. Existing best-effort disk-delete failures remain best effort. No original audio/index/schema/signing/package/release changes.
