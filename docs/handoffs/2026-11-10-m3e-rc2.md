## Why the number jumps from .1420 to .1685

The RC number is the Android APKs workflow's run number, a counter shared by every branch. RC1 was run .1420 (2026-10-24). The post-RC audit branches then used the runs up to .1681 (#701). RC2 is run **.1685**. No RC exists between them and nothing was skipped: the gap is other branches' CI runs.

  - **Return-to-app blink.** `onStop` published a null controller and the replacement connects after the first frame back, so the mini player left and returned, an open Now Playing began to close, and controls were disabled. The user confirmed the blink on their phone. The released controller now stays published until the replacement connects; a failed connection still publishes null. The position ticker ends with the connection. The controller is still released in `onStop`; service binding lifetime is unchanged.
  - **Previous restarts the song first.** The Previous buttons call Media3's `seekToPrevious()`: restart, or go back a song within the song's first three seconds. Swipes and their accessibility actions still go straight to the song before.
